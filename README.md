### `featured.project` ⚡

<div align="center">

```
╔══════════════════════════════════════════════════════════════════╗
║                                                                  ║
║   🔥  ANON-CHAT  —  Anonymous Realtime Chat Platform            ║
║                                                                  ║
║   Ephemeral. Lightweight. Built different.                       ║
║                                                                  ║
╚══════════════════════════════════════════════════════════════════╝
```

</div>

> **Why C++ for a chat backend?** Because Node.js was too easy.
> I wanted to understand what actually happens at the connection level —
> memory layout, socket handling, thread safety. C++ forced me to earn it.

| Layer | Technology |
|-------|-----------|
| 🔧 Backend | C++17 + Crow Framework |
| ⚡ Transport | WebSockets (full-duplex, realtime) |
| 🧠 Storage | RAM-only — ephemeral by design |
| 🐳 Deploy | Docker → Render |
| 🌐 Frontend | GitHub Pages |

```
Inspired by TempChat. Built as a free alternative.
University project turned systems experiment.
```
